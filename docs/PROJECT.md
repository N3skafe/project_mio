# 프로젝트

MaidOps Lab은 실제 터미널에서 쓰는 개발 조수다. 오리지널 고양이 수인 메이드 "미오"가 작업 상태를 말하고, 테스트 실행과 검토와 기록은 서비스가 처리한다. 캐릭터 채팅 앱이 아니다.

## 현재 단계

PHASE 5까지 구현되어 있다. DEMO TUI, LIVE API, 등록 명령 워커, 규칙 기반 라벨 초안, 사용자 검토, 원인·해결 메모, 키워드 검색, 확정 라벨 학습과 모델 비교가 포함된다.

임베딩 의미 검색과 근거 있는 답변은 아직 없다. 학습된 모델은 새 실패 로그의 초안을 바꾸지 않는다.

## 사용자가 하는 일

1. 등록된 가상 프로젝트의 테스트 시나리오를 실행한다.
2. 상태, 경과 시간, PASS / FAIL / CANCELLED 출력을 본다.
3. 실패 로그의 라벨 초안을 승인, 수정, 보류한다.
4. 승인 또는 수정한 사례에 원인과 해결 방법을 남긴다.
5. 이전 해결 기록을 키워드로 찾는다.
6. LIVE에서 확정 라벨이 학습 조건을 만족하면 학습을 시작하고, 끝난 모델을 규칙 baseline과 비교한 뒤 기본 모델을 고른다.

DEMO Lab은 학습하지 않고 점수를 만들지 않는다. 조건이 부족한 LIVE 학습도 점수를 만들지 않고 이유만 보여 준다.

## 원칙

- 단계마다 실행할 수 있는 결과물을 만든다.
- 가상 해결 기록은 `FIXTURE`, 실패 로그 초안은 `RULE_BASED`, 사용자 검토는 `USER`다. 학습 점수는 테스트 분할의 혼동행렬에서만 계산한다.
- 실패를 성공처럼 보여 주지 않는다.
- 세션 데이터는 종료되면 사라진다.
- 문서와 화면 문구는 한국어, 코드 식별자는 영어다.
